# 流式获取盘口最优价数据

要为某个金融工具打开实时盘口最优价(top-of-book)市场数据流,我们按以下格式向 websocket 写入一条消息:

`smd+CONID+{"fields":["field_1","field_2",...,"field_n"]}`

`fields` 数组中的值与向 `/iserver/marketdata/snapshot` 发送 HTTP 请求时使用的字段标签相同。这些字段标签值必须以 JSON 字符串的形式传递,并用双引号包裹。

例如,我们可以发送以下消息来获取 IBM 股票(conid 8314)的流式数据。

`smd+8314+{"fields":["31","84","85","86","88","7059"]}`

如果成功,我们将开始通过 websocket 接收以下格式的响应消息:

```{
  "31": "189.60",
  "6119": "q2",
  "6509": "RpB",
  "7059": "100",
  "84": "189.56",
  "85": "500",
  "86": "189.61",
  "88": "200",
  "_updated": 1712596911593,
  "conid": 8314,
  "conidEx": "8314",
  "server_id": "q2",
  "topic": "smd+8314"
}
```

我们可以通过发送以下消息来取消 websocket 上的盘口最优价数据流:

`umd+CONID+{}`

例如:

`umd+8314+{}`
