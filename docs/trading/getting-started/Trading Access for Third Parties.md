# 第三方交易接入

Interactive Brokers 将第三方开发者定义为这样一类软件供应商:其软件会与 IB 客户账户交互,而该供应商与这些账户在 IB 内部并无正式关系或访问权限。这与财务顾问或介绍经纪商(introducing broker)不同,后者与 IB 维持账户结构并正式管理客户账户。

目前,第三方供应商只能申请使用 OAuth1.0a 的审批。

第三方供应商的产品必须获得合规(Compliance)部门的批准后,集成才能继续进行。

第三方审批流程从提交第三方入驻(onboarding)问卷开始。

请注意,供应商应已设立商业实体,并在互联网上有公开 presence,提供描述其产品的材料。我们也强烈鼓励供应商构建概念验证(Proof of Concept)版本,以展示预期功能。入驻流程通常按以下步骤进行:

1. 我们的入驻团队会进行初步筛选。完成此步骤预计需要 2-3 周。如果我们的入驻团队可以继续处理您的审批请求,他们会将您的申请转交给我们的合规团队审核。
2. IBKR 合规部门会对所有第三方申请人进行强化尽职调查,随后进行三级审批流程。完成合规相关的审核与任务预计需要 3-6 周。
3. 如果合规部门批准,我们的法务团队将生成一份 Web API 协议,并转交给您审阅和签署。与此同时,我们的第三方入驻团队会要求您提供公钥和回调 URL(callback URL),以支持配置您的 OAuth1.0a consumer。到达该阶段后,我们将提供此过程的详细说明。IB 完成上述流程中我方负责的部分预计需要 3-5 周。

以上时间均为估计,可能有所变化。我们建议尽可能预先提供完整的信息,否则可能会延长所需时间。

在合规团队进行的强化尽职调查期间,他们会期望供应商拥有一个已完成的网站,其中包含最终确定的产品详情。这通常包括所有组件的清晰用户工作流,以及对其功能和能力的描述。

如果您的产品已获得合规批准,则在批准之后对产品进行的任何重大变更(例如增加交易功能),在向 IBKR 客户提供之前都需要经过我们合规团队的额外审核与批准。

请注意,我们期望提供自动化交易解决方案的第三方供应商,在其计划提供服务的所有地区持有金融监管机构要求的相应注册,除非供应商能够提供支持材料(即法律意见书),说明拟提供的服务为何在特定地区无需注册。此外,该产品还需要经过您打算为 IBKR 客户提供服务的所有地区的合规团队审核与批准。
