# 组织机构的交易访问权限

企业和机构客户可以使用多种授权与身份验证方法。所有方法都允许直接向 Interactive Brokers 的基础设施发起请求。

下面的列表概述了各种可用方法对不同用例的总体适用性。有关这些访问方法的更深入讨论,请联系我们的 API Integrations 团队。

* OAuth2.0 (beta)
  * 支持第一方(访问自己的账户)和第三方(经客户授权后访问非关联 IB 客户的账户)使用场景
  * 提供账户管理和交易功能的访问权限
* OAuth1.0a
  * 支持第一方(访问自己的账户)和第三方(经客户授权后访问非关联 IB 客户的账户)使用场景
  * 仅提供交易功能的访问权限
* SSO
  * 适用于财务顾问和介绍经纪商(Introducing Brokers)
  * 支持专门为您管理的客户开发替代性 UI
  * 提供账户管理和交易功能的访问权限
