# Trading API 支持

Interactive Brokers 随时欢迎客户联系我们的客户支持。我们提供多种方式直接联系我们的支持团队:

* [创建支持工单](https://www.interactivebrokers.com/en/general/contact/newContact/contact.php)
* [与 API 支持实时聊天](https://www.interactivebrokers.com/en/support/customer-service.php?p=chat)
* [通过电话获取帮助](https://www.interactivebrokers.com/en/support/customer-service.php?p=contact)

为了帮助加快故障排查过程,我们建议客户首先考虑以下几点:

* 该问题是否在其他平台上也存在?我是否能够通过 IB 的界面(如 Trader Workstation)而非 API 执行该操作(例如提交某个订单)?
* 该问题最早是在何时被发现的?相同的请求过去是否产生过不同的响应?
* 其他类似的请求是否能产生预期的响应?
* 请求中是否包含了我们 [Web API 参考资料](/web-api/api-reference/)中标记为*必填*的参数?

拥有[销售代表](https://www.interactivebrokers.com/en/support/institutional-sales-contacts.php)的客户也可以考虑让其代表参与进来,他们可以协助将咨询转达给相应的团队。
