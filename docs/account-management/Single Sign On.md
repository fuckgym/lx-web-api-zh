# 单点登录

`/api/v1/sso-browser-sessions` 端点可用于创建单点登录(SSO)会话,将用户无缝连接至 IBKR Client Portal。IBKR Client Portal 是一个基于浏览器的界面,用户可以在其中查看投资组合信息、管理账户设置、管理订单、发起资金划转以及查看对账单。若配置了白标品牌(white branding),门户将呈现托管公司的品牌(logo、公司名称、配色主题)。目标页面的参数对大小写和空格敏感。

#### 工作流程

1. 托管公司将调用 `/api/v1/sso-browser-sessions`,并提供最终用户的 `credential` 和 `ip`。
   * `credential:`与该用户关联的 IBKR 用户名。
   * `ip:`必须为静态 IP,且必须是客户实际使用的计算机(即其 IP-REMOTE\_ADDR)。
   * ***示例***
     * `POST /api/v1/sso-browser-sessions { "ip": "206.106.137.230", "credential": "potest123"}`
2. IBKR 返回一个带有 SID(唯一令牌)的响应 URL。托管公司将在用户浏览器中调用该带 SID 令牌的 URL,新窗口随即打开,用户进入 IBKR 白标品牌门户。
   * SID 仅在 60 秒内有效,且只能通过原始请求中包含的 IP 访问。
   * 如果唯一 SID 被访问多次、在 60 秒之后才输入,或者访问 SID 所用的 IP 与创建单点登录会话的原始请求中传递的 IP 不同,则会触发错误。
   * ***IBKR 响应示例***
     * `https://www.clientam.com/sso/resolver?<SID=<asdfsadf>`
3. 可选操作:通过在 URL 后追加 ACTION 来设置“目标”页面
   * 有关设置目标页面(包括可用操作)的详细信息,请参见[此处](https://www.interactivebrokers.com/campus/ibkr-api-page/web-api-account-management/#single-sign-on)。
     * ***将对账单设为目标页面时的 URL 示例***
       * `https://www.clientam.com/sso/resolver?ACTION=Statement&SID=<asdfsadf>`

#### 限制

* SSO 仅支持浏览器(桌面浏览器或移动浏览器)。SSO 不支持原生安装的移动应用程序。
* 账户初次创建时,IBKR 会为该账户分配一个临时密码。这是一次性设置,要求用户在账户创建后重置该临时密码。
* 在使用 IBKR 托管门户添加出金指令和发起出金请求时,需要使用 IBKR 凭据(用户名)和密码进行身份验证。

### 设置目标页面

默认情况下,当您为已开通的账户创建 SSO 会话时,用户将进入 Client Portal 主页。不过,您可以在启动调用中添加 `ACTION` 参数,将用户引导至特定的目标页面。

如果设置了目标页面,默认会显示 IBKR 导航面板,允许用户访问门户中目标页面之外的其他功能。

为提供更简洁的体验,我们提供“IFRAME”选项,可移除 IBKR 导航面板。要创建 IFRAME,只需在 SSO URL 中包含 `showNavBar=false` 即可。

| SSO - 标准                                                           | 使用 IFRAME 的 SSO                                                                  |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| ACTION=TransferFunds\&method=WIRE\&type=WITHDRAWAL\&currency=**USD** | ACTION=TransferFunds\&method=WIRE\&type=WITHDRAWAL\&currency=USD\&showNavBar=false |
|                                                                      |                                                                                    |

### 请求参数

| 参数         | 类型                                       | 用法                                                                                                                                                                                                                                                                                                      |
| ---------- | ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ACTION     | 因操作而异,见下表。                               | 可选 - 若未设置或无效,用户将被引导至 Client Portal 主页。                                                                                                                                                                                                                          |
| showNavBar | true false                               | 可选 - 若缺失或设置为 true,用户将进入 Client Portal 主页。若设置为 false,则不显示导航栏,从而创建“IFRAME”。showNavBar=false 仅对部分功能受支持。若对不支持的功能进行设置,用户将进入 Client Portal 主页。 |
