# 简介

注册任务(Registration tasks)表示在 IBKR 激活或维持经纪账户所需的任务。

* 任务包括申请流程中的步骤、客户协议与披露文件、税务表格、用于审批的证明文件,以及额外的核验任务(强化尽职调查,Enhanced Due Diligence)。
* 任务可用于跟踪账户的生命周期,并识别是否需要客户采取行动才能继续审批流程。

查看与账户关联的注册任务时,将返回以下属性:

| 属性                | 描述                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| formNumber          | IBKR 与该注册任务关联的 4 位数字编号。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| formName            | 表格名称。formNumber 与 formName 始终是一一对应的。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| onlineTask          | True = 需要由客户完成/签署的 IBKR 表格。  False = 需要由客户发送给 IBKR 的外部文档。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| requiredForTrading  | True = 在该在线任务完成之前,申请人将无法下单交易。   False = 在任务完成之前,申请人即可下单交易。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| requiredForApproval | True = 在该任务完成之前,账户将不会获得批准/开立。  False = 审批不需要该任务。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| action              | 描述与任务相关联的操作。  **to be sent(待发送)** = 需要由客户发送给 IBKR 的外部文档。    **to complete(待完成)** = 需要通过 IBKR Client Portal 完成的在线步骤   **to sign(待签署)** = 需要申请人电子签名的 IBKR 协议或表格。这些可以通过 IBKR Client Portal 签署,或通过 API 提交  **待处理的申请** 1. Full Integration(完全集成)——表格必须使用 'DocumentSubmission' 提交给 IBKR 2. Hybrid Integration(混合集成)——表格必须由客户在 IBKR Client Portal 内签署  **已开立的账户** 已签署的表格可以通过 API 使用 "DocumentSubmission" 提交给 IBKR,或由客户在 IBKR Client Portal 内签署 |
| state               | 任务的当前状态 –  **To Be Sent(待发送)–** 需要提交给 IBKR 的外部文档。  **To Be Signed(待签署)** – 需要由客户签署的 IBKR 协议/披露文件。  **To Be Submitted(待提交)–**  需要提交给 IBKR 的 IBKR 生成文档。**To Be Completed(待完成)** – 需要完成的在线任务。  **Received- Being Processed(已接收-处理中)–** 文档正由 IBKR 审核。  **Rejected .. \<拒绝原因>** – 外部文档被 IBKR 拒绝。请提交符合 IBKR 要求的新文档,以继续审批流程。                                                                                                                                                                                                                                                                                                   |
