# 查看注册任务

IBKR 会在通过 API 创建账户时所返回的响应文件中包含注册任务的状态。

`documents:` 表示通过 API 创建账户时已包含并已处理的任务。

`pendingTasks`:表示账户审批所需的任务。托管机构(hosting firm)负责将审批所需的待办任务告知最终用户。

`gw/api/v1/accounts/{accountId}/tasks` 可用于查看账户创建后与该账户关联的注册任务。

IBKR 将任务分为**两种类型**:

**`type=pending:`** 查看账户审批**所必需**的待处理(未完成)注册任务。

* 如果某个注册任务被分配给一个待审批(pending)账户,且该任务并非账户审批所必需,则该任务不会在响应中返回。
* 如果某个注册任务被分配给一个已开户(opened)账户,且该任务是账户升级所必需的,则该任务不会在响应中返回。

**`type=registration`**:查看与账户关联的所有任务,无论账户状态或注册任务的状态如何。

* 查看用户完成特定注册任务的日期/时间。
* 查看客户为在 IBKR 进行交易或维持账户而需要完成的注册任务。
