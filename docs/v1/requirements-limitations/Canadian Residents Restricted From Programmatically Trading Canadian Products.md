# 加拿大居民被限制以编程方式交易加拿大产品

Interactive Brokers Canada Inc.(IBC)不允许用户使用自己的交易应用程序通过 API 以电子方式提交在加拿大交易所或其他市场交易的产品的订单,这也包括第三方集成。这一决定是 IBC 合规部门及相关人员与加拿大投资监管组织(Canadian Investment Regulatory Organization,CIRO,前身为加拿大投资行业监管组织(Investment Industry Regulatory Organization of Canada,IIROC),即我们的自律组织)的高级管理层经过多次深入沟通后做出的。

CIRO 已实施 [IIROC Dealer Member Rule (DMR) 3200](https://www.ciro.ca/sites/default/files/legacy/2021-09/RulesCollated_090121_en.pdf) A. 1. (b) (i),该规则禁止 CIRO 注册机构(包括 IBC)允许其客户使用自己的自动化订单系统生成订单。

遗憾的是,这些限制同样适用于使用 API 连接的第三方应用程序,例如 TradingView、NinjaTrader 或其他类似平台。
