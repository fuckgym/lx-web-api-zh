# 定期服务器维护

Interactive Brokers 为 Web API 的所有用户安排了定期维护。系统重置时间与标准 Trader Workstation 连接的重置时间不同。客户端会在其所在连接区域的午夜时分看到断开连接。

| 服务器重置时间                 | 北美             | 欧洲       | 亚洲      |
| ------------------------------ | ---------------- | ---------- | --------- |
| **当地时间**                   | 00:00 US/Eastern | 00:00 CEST | 00:00 HKT |
| **协调世界时**                 | 20:00 UTC        | 02:00 UTC  | 08:00 UTC |
