# 不可用的历史数据

* 历史数据默认会被过滤。更多信息请参阅我们的 FAQ,[点击此处](https://www.interactivebrokers.com/lib/cstools/faq/#/content/102546341)。
* bar 大小为 30 秒或更小、且时间早于六个月前的数据
* 自期货到期日起算,超过两年的已到期期货数据。
* 已到期的期权、期货期权(FOP)、权证和结构性产品。
* 期权、期货期权、权证和结构性产品的日终(EOD)数据。
* 已到期期货价差的数据
* 超过 6 个月的债券数据
* 已不再交易的证券的数据。
* 组合(combo)的原生历史数据。历史数据不会针对组合单独存储在 IB 数据库中;TWS 或 API 中的组合历史数据是其各腿(leg)数据之和。
* 迁移至新交易所的证券,其迁移之前的历史数据通常不可用。
* 诸如加权移动平均线或布林带(Bollinger Bands)等研究和指标无法通过 API 获得。
