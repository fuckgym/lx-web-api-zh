# 简介

Interactive Brokers 将事件合约(Event Contract)工具建模为期权(针对 ForecastEx 产品)和期货期权(针对 CME Group 产品)。

在 Web API 中,事件合约通常可以被视为期权类产品,其发现流程遵循与期权类似的熟悉顺序。本指南将针对 ForecastEx 和 CME Group 产品,与常规指数期权进行类比。

IB 的事件合约工具记录使用从期权模型继承的以下字段:

* 一个**标的(underlier)**,可能是人工构造的,也可能不是:
  * 对于 **CME 产品**,可交易的事件合约将以相关的 CME 期货作为其标的。
  * 对于 **ForecastEx 产品**,IB 生成了一个人工构造的底层指数,作为同一产品类别中相关事件合约的容器。这些人工指数没有任何关联的参考值,纯粹是用于表示这些事件合约的期权工具模型的产物。不过,与指数期权一样,这些人工底层指数可用于搜索相关事件合约组。
* 一个 **Symbol** 值,与标的的符号一致,反映发行方的产品代码。
* 一个 **Trading Class(交易类别)**,同样反映该工具的发行方产品代码;对于 CME Group 产品,它用于将事件合约与 CME 期货期权区分开来。
  * 请注意,许多针对 CME Group 期货解析的 CME Group 事件合约,其 Trading Class 会被分配以 "EC" 为前缀、后接相关期货产品符号的名称,以避免与其他衍生品(即在同一期货上正式上市的期货期权)命名冲突。
* 一个 **Put or Call(Right)** 值,其中 Call = Yes,Put = No。
  * 请注意,ForecastEx 工具不允许卖出(Sell)订单。相反,ForecastEx 持仓通过买入相反方向的合约来平仓或减少。CME Group 事件合约则允许买入和卖出。
* 一个人工构造的 **Contract Month(合约月份)** 值,同样主要用于搜索和筛选可用工具。大多数事件合约产品并不遵循指数期权或股票期权常见的月度序列,因此这些合约月份值通常不是工具有意义的属性。它们主要用于按日历月份筛选工具。
* **Last Trade Date、Time 和 Millisecond(最后交易日、时间与毫秒)** 值,共同精确指示事件合约交易何时终止,与指数期权一样。
* 一个 **Expected Resolution Time(预期解析时间)**,即被追踪事件的结果公布、合约被判定为价内或价外的时间。这通常被称为合约的"到期日"。
* 一个 **Expected Payout Time(预期派付时间)**,即合约被结算并从账户中移除的时间。到期处于价内的合约将获得派付。
* 一个 **Measured Period(测量周期)**,在合约问题的定义中给出。这是用于组织合约(如同期权链)的主要日期。
* 一个 **Strike(行权价)** 值,即事件解析所依据的数值。虽然它是数值,但不一定代表价格。
* 一个**工具描述(或 "local symbol")**,格式为 `"PRODUCT EXPIRATION STRIKE RIGHT"`,其中:
  * `PRODUCT` 是发行方的产品标识符
  * `EXPIRATION` 是该工具解析日期,格式为 `MmmDD'YY`,例如 "Sep26'24"
  * `STRIKE` 是决定合约到期时价内/价外状态的数值
  * `RIGHT` 的取值为 YES 或 NO
