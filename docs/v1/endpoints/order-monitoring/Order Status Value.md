# 订单状态值

对于许多订单，客户会看到订单返回一个订单状态，该状态带有一组可能的取值。下表详细说明了各状态对订单的含义以及可以预期的后续行为。

Live Orders 对象中 "order\_status" 字段返回的值，与使用 [GET /iserver/account/orders](/web-api/v1/endpoints/order-monitoring/live-orders) 的 "filters" 参数时所采用的格式略有不同。

######

| 状态           | 筛选值（Filter Value） | 描述                                                                                                                                                                                                                                                                                                         |
| ------------- | --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Inactive      | inactive        | 表示您正在创建订单的过程中，尚未激活或传送（transmit）该订单。                                                                                                                                                                                                                                                               |
| PendingSubmit | pending\_submit | 表示您已传送订单，但尚未收到订单目的地（order destination）接受该订单的确认。                                                                                                                                                                                                                                              |
| PreSubmitted  | pre\_submitted  | 表示订单已被系统（模拟订单）或交易所（原生订单）接受，且该订单尚未被触发（elected）。                                                                                                                                                                                                                                           |
| Submitted     | submitted       | 表示您的订单已被接受，并正在目的地正常生效（working）。                                                                                                                                                                                                                                                                |
| Filled        | filled          | 订单已全部成交。                                                                                                                                                                                                                                                                                                |
| PendingCancel | pending\_cancel | 表示您已发送取消订单的请求，但尚未收到来自订单目的地的取消确认。此时，您的订单尚未确认被取消。在取消请求待处理期间，您仍可能收到成交回报。                                                                                                                                                              |
| PreCancelled  | pre\_cancelled  | 表示取消请求已被系统接受，但由于系统、交易所或其他问题，该请求目前未被识别。此时，您的订单尚未确认被取消。在取消请求待处理期间，您仍可能收到成交回报。                                                                                                                              |
| Cancelled     | cancelled       | 表示订单的剩余部分已被系统确认取消。当目的地拒绝了您的订单时，可能会意外出现这种情况。                                                                                                                                                                                                                |
| WarnState     | warn\_state     | 订单带有特定的警告消息，例如篮子订单（basket order）。                                                                                                                                                                                                                                                            |
| N/A           | sort\_by\_time  | 系统会先按订单状态进行初始排序，使活跃订单始终位于未激活和已成交订单之上，然后再按时间顺序对订单排序。                                                                                                                                                                                                            |
