# FYI 类型代码(Typecodes)

许多 FYI 端点都会引用 "typecode" 值。下表列出了可用的代码及其对应含义。

| 类型代码 | 说明                                        |   |                        |
| -------- | ------------------------------------------- | - | ---------------------- |
| BA       | 融券可用性(Borrow Availability)            |   |                        |
| CA       | 可比算法(Comparable Algo)                  |   |                        |
| DA       | 股息顾问(Dividends Advisory)               |   |                        |
| EA       | 即将公布的财报(Upcoming Earnings)          |   |                        |
| MF       | 共同基金顾问(Mutual Fund Advisory)         |   |                        |
| OE       | 期权到期(Option Expiration)                |   |                        |
| PR       | 投资组合构建器再平衡(Portfolio Builder Rebalance) |   |                        |
| SE       | 经济事件暂停订单(Suspend Order on Economic Event) |   |                        |
| SG       | 短期收益转为长期(Short Term Gain turning Long Term) |   |                        |
| SM       | 系统消息(System Messages)                  |   |                        |
| T2       | 行权实现长期收益(Assignment Realizing Long-Term Gains) |   |                        |
| TO       | 收购(Takeover)                             |   |                        |
| UA       | 用户提醒(User Alert)                       |   |                        |
| M8       | M871 交易(M871 Trades)                     |   |                        |
| PS       | 平台使用建议(Platform Use Suggestions)     |   |                        |
| DL       | 未行权期权损失预防提醒(Unexercised Option Loss Prevention Reminder) |   |                        |
| PT       | 持仓划转(Position Transfer)                |   |                        |
| CB       | 缺失成本基础(Missing Cost Basis)           |   |                        |
| MS       | 里程碑(Milestones)                         |   |                        |
| TD       | MiFID                                       |   | 10% 弃用通知            |
| ST       | 节税(Save Taxes)                           |   |                        |
| TI       | 交易点子(Trade Idea)                       |   |                        |
| CT       | 资金划转(Cash Transfer)                    |   |                        |
