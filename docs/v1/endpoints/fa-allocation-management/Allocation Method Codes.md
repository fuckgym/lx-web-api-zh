# 分配方法代码

Interactive Brokers 支持两类分配方法:由 Interactive Brokers 完成计算的分配方法,以及由用户自行计算后再行指定的分配方法。

#### IB 计算的分配方法

| 方法                 | 代码 |
| -------------------- | ---- |
| Available Equity     | A    |
| Equal                | E    |
| Net Liquidation Value | N    |

#### 用户指定的分配方法

###### 旧称 Allocation Profiles

| 方法          | 代码 |
| ------------- | ---- |
| Cash Quantity | C    |
| Percentages   | P    |
| Ratios        | R    |
| Shares        | S    |
