# 安装与身份验证

#### 创建 IBKR 账户

如果您尚未拥有账户,请创建一个 IBKR Pro 账户并入金。

#### 安装 Java

如果您没有可正常使用的 Java 版本,请从[官方网站](https://www.java.com/en/download/)下载。

您可以在终端中运行以下命令来检查是否已正确安装 Java:`java -version`

#### 下载 Client Portal Gateway

下载

解压下载的文件。

#### 运行 API Gateway

在终端中进入解压后的 clientportal.gw 目录。例如:`cd C:/Users/Example/Downloads/clientportal.gw`

使用以下命令启动网关:`bin\run.bat root\conf.yaml`

#### 登录

访问 [https://localhost:5000](https://localhost:5000)。使用您的标准 Interactive Brokers 凭据登录。
