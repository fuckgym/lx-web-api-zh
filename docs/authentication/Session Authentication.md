# 会话身份验证

要接收市场数据、下订单,以及普遍使用所有 /iserver 端点,都需要经过身份验证的经纪会话。经纪会话(或交易会话)由用户名(您的凭据)建立,该用户名进而拥有对一个或多个账户(实际的资金池)的交易权限。单个用户名同一时间只能有一个处于活动状态的交易(或"经纪")会话。一般交易权限/特定资产类别的交易权限、市场数据订阅(从而访问所订阅的数据源)等均由用户名而非底层账户承载。因此,提及经纪会话时,指的是与 IBKR 后端交易基础设施保持连接的已登录用户名。

对于 OAuth 1.0a,访问令牌(Access Token)在初始注册时即直接与用户绑定。对于 OAuth 2.0,凭据值直接与经过身份验证的用户会话相关联。

## 有关 Web API 会话的背景知识

1. 一个 IB 用户名一次只能打开一个经纪会话,即在任意给定时刻,它只能在一个平台(TWS、Client Portal 等)上交易并使用类似的受限功能。切换到另一个平台进行交易需要关闭现有的经纪会话,并从新平台开启一个新的经纪会话。
2. Web API 会话通常是两层的:
   * 一个"外层"前提条件"只读会话(read-only session)",必须处于活动/有效状态才能发出任何 Web API 请求,但它本身仅允许访问**非 /iserver** 端点。
   * 在只读会话之后建立的"经纪会话",允许访问交易、市场数据消费以及 **/iserver** 端点背后的所有其他功能。
3. 这种两层结构反映了我们的 Client Portal 网站的运作方式:当某用户名已在其他地方(例如 TWS)登录经纪会话时,仍允许您以只读会话登录进行账户管理,而不影响 TWS 的经纪会话。
