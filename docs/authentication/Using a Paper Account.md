# 使用模拟账户

我们鼓励客户在进入 Web API 实盘测试之前,先使用其模拟账户(Paper account)进行身份验证和测试。用户可能会注意到,与 Interactive Brokers 的其他部分不同,这里没有用于指示实盘账户或模拟账户登录的滑动开关。因此,客户必须使用其特定的模拟账户用户名进行身份验证。

您可以按照以下步骤找到您的模拟账户用户名:

1. 登录[客户门户(Client Portal)](https://ndcdyn.interactivebrokers.com/sso/Login)
2. 选择右上角的人像图标(Head & Shoulders Icon)。
3. 点击 "Settings"。
4. 在左侧 "Account Configuration" 下选择 "Paper Trading Account"
5. 您将看到模拟交易用户名(Paper Trading Username)、模拟交易账号(Paper Trading Account Number),以及关联市场数据的选项。
   * 如果您还不知道密码,建议选择 "Reset Paper Trading Password" 以设置一个专门用于模拟交易的唯一密码。该密码可以随时重置。

现在,您可以使用新获取的模拟交易用户名和密码登录 Client Portal Gateway。
