# 快速入门

### 零售客户

对于零售和个人客户,我们的 WebAPI 身份验证通过 Client Portal Gateway 进行管理,这是一个用于以适当的身份验证方式路由本地 Web 请求的小型 Java 程序。点击[这里](/web-api/authentication/cpgw/installation-authentication)开始使用。

### 机构或第三方

我们理解企业级集成可能更为复杂。我们设有专门的 API Solutions 团队,将协助您创建符合业务目标的解决方案。如需开始,请通过以下信息联系我们的 API Solutions 团队(电子邮件:**[api-solutions@interactivebrokers.com](mailto:api-solutions@interactivebrokers.com)**):

* 公司名称
* 公司类型(即介绍经纪商(Introducing Broker)、财务顾问(Financial Advisor)或第三方服务提供商)
* 您有兴趣使用的 API 服务(即注册、入金、单点登录、查看投资组合数据、交易、报告)
* 描述预期用途(1-2 句话)
