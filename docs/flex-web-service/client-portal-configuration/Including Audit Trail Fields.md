# 包含审计追踪字段

"Audit Trail Field"(审计追踪字段)选项将选择从审计追踪(Audit Trail)而非前端资源中检索数据。这会直接影响某些 Section(小节)及其中的选项所能返回的数据。例如,只有在 Audit Trail Fields 设置为 "Yes" 时,才会显示 **OrderReference**。

这一设置同样适用于 Brokerage Order ID、Order Reference、Volatility Order Link 和 Order Placement Time。

**注意:** 这些功能目前不适用于模拟交易账户,仅在实盘交易环境中可用。
