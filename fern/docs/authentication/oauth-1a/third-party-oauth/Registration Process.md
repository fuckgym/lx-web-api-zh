# 注册流程

Interactive Brokers 将第三方实体定义为:向组织以外的个人提供交易平台或交易媒介的任何组织。请注意,希望注册为 Interactive Brokers 第三方的团体,必须已拥有与其他经纪商合作的成熟平台,或已使用 Web API 完成完整的可行性验证(proof of concept)。

相关示例包括自动交易程序(auto-trader)或智能投顾(robo-advisor)、公开的移动应用程序,以及转发市场数据的团体。

对于符合上述标准并有意与 Interactive Brokers 整合的组织,请发送电子邮件至 [api-solutions@interactivebrokers.com](mailto:api-solutions@interactivebrokers.com)。

为了让您对后续流程有所了解:

1. 我们的入驻(onboarding)团队会进行初步审查。在收集到足够的信息后,我们将完成初步评估。完成此步骤预计需要 2-3 周。如果我们可以继续推进,我们会将您的申请提交给合规(Compliance)团队审核。
2. IBKR 合规团队会对所有第三方申请人进行强化尽职调查,随后进行三级审批流程。完成合规相关审核和任务预计需要 3-6 周。
3. 如果获得合规批准,我们的法务团队将生成 WebAPI 协议并发送给您审阅和签署。与此同时,我们会要求您提供公钥和回调 URL(CallbackURL),这些是生成您的消费者密钥(consumer key)并完成设置所必需的。到达该阶段后,我们将提供此过程的详细说明。我方完成上述工作和流程预计需要 3-5 周。

以上时间均为估计值,可能有所变化。我们建议尽可能预先提供完整的信息,否则可能会延长所需时间。

在合规团队进行的强化尽职调查中,他们期望看到希望向我们的客户提供服务的第三方供应商拥有一个已完成的网站,其中详细说明将提供的所有功能/服务,以及其服务的最终细节。这通常包括所有组件清晰的用户工作流程,以及其功能和能力的详细说明。

如前所述,如果获得合规批准,我们将为您生成一个可用的消费者密钥;在获批之后,若服务内容发生重大变化(例如增加交易功能),则需要经过我们合规团队的额外审核和批准,才能向 IBKR 客户提供服务。

请注意,我们期望提供自动交易解决方案的第三方,在其计划提供服务的所有地区均持有金融监管机构颁发的相应注册资质,除非您能够就为何所提供的业务在该地区无需注册提供支持材料(例如法律意见书)。此外,该服务还需经过您打算支持 IBKR 客户的所有地区合规团队的审核和批准。

以上时间均为估计值,可能有所变化。我们建议尽可能预先提供完整的信息,否则可能会延长所需时间。
