# 管理多个会话

在任何用户名下,所有 IBKR 服务中只能存在一个活动的经纪会话。如果您已登录 Client Portal、TWS 或 IBKR Mobile 中的任一服务,请务必先登出,然后重新尝试对您的 Web API 会话进行身份验证。

希望同时使用多个 IBKR 产品(TWS、IBKR Mobile 或 Client Portal)的客户,可以通过创建一个新用户名来实现——在使用 Web API 的同时,用该新用户名登录其他服务。要创建第二个用户名,请参阅以下 [IBKR Knowledge Base](https://ibkr.info/node/1004) 文章。

**注意:** 根据市场数据供应商的要求,市场数据服务是与用户绑定的,任何订阅了市场数据的用户名都将被单独收取市场数据订阅费。
