# 支持的双因素认证(2FA)

Interactive Brokers 在其各平台上支持种类繁多的 2FA 系统。由于 API 不支持账户管理功能,某些 2FA 方式不受支持。在尝试通过我们的 API 系统进行身份验证时,请确保账户已启用受支持的 2FA 方式。

Interactive Brokers 的所有用户均须使用双因素认证(2FA)。

#### 受支持的 2FA 方式

* IB Key
* Handy Key(智能手机应用)
* SMS / 文本消息
* Digital Security Card+(DSC+)

#### 不受支持的 2FA 方式

* Security Code Card(有时称为 Bingo Card)
* Temporary Security Code Card
* Online Code Card
