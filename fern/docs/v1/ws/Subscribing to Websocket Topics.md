# 订阅 Websocket 主题

通过 websocket 提供的大多数数据都是作为消息流发送的，响应于对某个主题的显式订阅。这类订阅消息属于"主动请求型"（solicited），因为客户端必须先请求订阅相关主题，服务器才会发送消息。要订阅某个主题，需按以下格式向 websocket 发送一条消息：

**TOPIC+\[TOPIC\_TARGET]+\{PARAMETERS}**

其中：

* **TOPIC** 是要订阅的主题（数据类型）的标识符。
* 加号 **+** 用作消息各元素之间的分隔符。
* **TOPIC\_TARGET** 标识特定资源（通常是账户或金融工具）作为订阅的对象。某些主题不使用目标。\* **\{PARAMETERS}** 是一个 JSON 格式的字符串，用于描述主题订阅的过滤器或其他修饰符。如果该主题没有可用参数，或者你的订阅不需要任何参数，则发送一个空的 \{} 对象。

主动请求型消息主题的长度通常为三个字符。发送订阅的消息，以及在订阅持续期间收到的响应消息，都会使用以 **s**（"subscribe"）开头的主题。后两个字符标识所涉及的具体数据源，例如主题 **ssd**，表示 "subscribe" + "account summary"（账户摘要）。

取消订阅时，发送的消息使用以 **u**（"unsubscribe"）开头的主题，后跟将被终止订阅的数据源的两字符标识符，例如主题 **usd**，表示 "unsubscribe" + "account summary"。服务器会以相同的取消订阅主题返回一条响应消息，确认取消订阅。
