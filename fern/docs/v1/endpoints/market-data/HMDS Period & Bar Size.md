# HMDS 周期与 Bar 大小

#### 有效的周期单位：

| 单位 | 描述 |
| ---- | ----------- |
| S    | 秒          |
| d    | 天          |
| w    | 周          |
| m    | 月          |
| y    | 年          |

注意：这些单位区分大小写。

#### 有效的 Bar 单位：

| 时长              | 允许的 Bar 单位    | Bar 大小区间（最小/最大） |                 |                    |                  |
| ----------------- | ----------------- | --------------------------- | --------------- | ------------------ | ---------------- |
| 60 S              | secs              | mins                        | 1 secs -> 1mins |                    |                  |
| 3600 S（1 小时）  | secs              | mins                        | hrs             | 5 secs -> 1 hours  |                  |
| 14400 S（4 小时） | sec               | mins                        | hrs             | 10 secs -> 4 hrs   |                  |
| 28800 S（8 小时） | sec               | mins                        | hrs             | 30 secs -> 8 hrs   |                  |
| 1 d               | mins              | hrs                         | d               | 1 mins-> 1 day     |                  |
| 1 w               | mins              | hrs                         | d               | w                  | 3 mins -> 1 week |
| 1 m               | mins              | d                           | w               | 30 mins -> 1 month |                  |
| 1 y               | d                 | w                           | m               | 1 d -> 1 m         |                  |

注意：这些单位区分大小写。

**注意**：请记住，步长（step size）定义为历史数据请求的时长周期与其粒度（即 bar 大小）之间的比率。历史数据请求的构造方式必须保证一次只返回几千根 bar。
