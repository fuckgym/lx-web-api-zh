# 市场数据可用性

该字段可包含三个字符。

第一个字符定义市场数据时间线。包括:R = RealTime,D = Delayed,Z = Frozen,Y = Frozen Delayed,N = Not Subscribed。

第二个字符定义数据结构。包括:P = Snapshot,p = Consolidated。

第三个字符定义数据类型:始终返回:B = Book

| 代码 | 名称                                       | 描述                                                                                                                                                                                                                                                                                                                                    |
| ---- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R    | RealTime                                   | 数据实时无延迟地回传,需要相应的市场数据订阅。                                                                                                                                                                                                                                                                                             |
| D    | Delayed                                    | 数据延迟 15-20 分钟回传。                                                                                                                                                                                                                                                                                                                |
| Z    | Frozen                                     | 市场收盘时最后记录的数据,实时回传。                                                                                                                                                                                                                                                                                                       |
| Y    | Frozen Delayed                             | 市场收盘时最后记录的数据,延迟回传。                                                                                                                                                                                                                                                                                                       |
| N    | Not Subscribed                             | 用户没有所需的市场数据订阅,无法回传实时或延迟数据。                                                                                                                                                                                                                                                                                        |
| O    | Incomplete Market Data API Acknowledgement | 该用户尚未完成年度 Market Data API 确认。要完成该协议:1. 登录 2. 在右上角选择"Welcome",然后选择"Settings" 3. 你会在右侧看到一个大的"Market Data Subscriptions"按钮。4. 在右侧找到"Market Data API Agreement"。                                                                                                                              |
| P    | Snapshot                                   | 该合约可进行快照(snapshot)请求。                                                                                                                                                                                                                                                                                                          |
| p    | Consolidated                               | 市场数据聚合自多个交易所或交易场所。                                                                                                                                                                                                                                                                                                       |
| B    | Book                                       | 该合约可获得盘口顶层(top of the book)数据。                                                                                                                                                                                                                                                                                                |
| d    | Performance Details Enabled                | 该合约可获得更多表现详情。仅供内部使用。                                                                                                                                                                                                                                                                                                    |
