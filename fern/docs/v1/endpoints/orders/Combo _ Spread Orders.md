# 组合 / 价差订单

组合订单(combo order)或价差订单(spread order)也可以使用相同的订单端点提交。对于组合订单,我们必须使用 'conidex' 而不是 "conid"。conidex 字段是组合订单参数的字符串表示形式。

**组合订单遵循以下格式:'\{spread\_conid};;;\{leg\_conid1}/\{ratio},\{leg\_conid2}/\{ratio}'**

spread\_conid 是用于标识价差订单的唯一标识符。对于美股组合(US Stock Combos),只需提交 spread\_conid 即可。对于其他国家/地区,您需要使用 'spread\_conid\@exchange' 格式。

在 spread\_conid 之后,接着输入 3 个分号,然后是第一个 leg\_coind(腿合约)。这是第一个要交易的合约。在 conid 之后,需要包含一个正斜杠 '/',后跟您的价差比率(ratio)。

比率包含两部分含义。第一部分是比率的正负号,即正还是负。正号表示 'Buy'(买)方向,负值表示 'Sell'(卖)方向。也可以根据您当前的持仓和意图,将其理解为 'Long'(多头)和 'Short'(空头)状态。在标明方向后,您需要指明比率值。这是您数量值的乘数。

现在,您可以继续用逗号分隔的方式向订单添加更多腿(leg)。可用腿的数量取决于交易所的规则。

#### 组合订单定价

组合订单提交价格时,基于每条腿的价值乘以其比率来计算,然后将每条腿的价格相加,得到订单的最终价格。

如果其中一条腿是被卖出,且该腿价值乘以比率后的总值大于其他订单的价值,则这些价格最终可能为负值。

组合订单的价格 = \[(\{第 1 条腿的成本} \* \{第 1 条腿的比率}) + (\{第 n 条腿的成本} \* \{第 n 条腿的比率}) + (\{第 n+1 条腿的成本} \* \{第 n+1 条腿的比率})]
