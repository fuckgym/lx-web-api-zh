# 计划内服务器维护

Interactive Brokers 会为承载 Web API 的基础设施进行计划内维护。在维护窗口期间,Web API 的某些功能会短暂不可用。

Web API 维护窗口的时间与其他平台(如 Trader Workstation)所观察到的时间略有不同。

Web API 本身在工作日全天 24 小时可访问,仅在周六晚上进行维护。

经纪功能(由 `/iserver` 端点提供)每晚按各地区当地时间约 0100 左右短暂不可用。

##### *工作日 IServer 重置时间*

| 地区                             | 维护开始时间        |
| -------------------------------- | ----------------- |
| 北美洲 *(纽约和芝加哥)* | 01:00 US/Eastern  |
| 欧洲                             | 01:00 CEST        |
| 亚洲                             | 01:00 HKT         |
