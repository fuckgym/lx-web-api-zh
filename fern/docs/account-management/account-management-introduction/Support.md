# 支持

IBKR 设有专门的 API 团队,通过电子邮件提供 24/5 支持,并将在集成过程中作为主要联络点。

* 账户管理 API:****am-api@**interactivebrokers**.com****
* 交易 API:**api@**interactivebrokers**.com**

### 我们提供的服务

找准从哪里开始是最难的部分。为帮助您入门,我们创建了指南和 API 参考,其中包含为客户端注册、账户维护、交易和投资组合管理编写接口所需的一切内容。您专属的集成经理将在整个集成过程中以及上线后最多 3 个月内,每周与您进行电话会议。

### 资源

为了帮助您更好地理解 API 端点,我们建议安装 [postman](https://www.postman.com/downloads/),并安装我们的 [postman collection](/web-api/account-management/resources/postman) 和环境。
