# 回调通知(Callback Notifications)

当请求状态发生变化时,IBKR 会通过 RESTful Web API 发送通知。通过回调服务提供的通知与轮询状态所获得的格式相同(即 `/gw/api/v1/accounts/{accountId}/status`)。对于通过 Account Management API 和 IBKR Portal 发起的客户注册(Client Registration)、账户信息变更以及资金请求,均提供通知服务。

## 启用回调服务

1. 回调服务仅可应请求提供。如需配置该服务,请将以下信息提供给 [am-api@interactivebrokers.com](mailto:am-api@interactivebrokers.com):
   * 回调通知应发送到的 URL
   * 需要为其配置回调服务的主账户 ID
2. IBKR 将注册该 URL 并为您的账户配置回调服务。这可能需要 2-3 周时间。
   * 已启用回调通知的客户仍可不受任何限制地使用状态轮询(Polling)。

#### 查看回调通知

回调通知以已签名的 JWT 形式发送。

* Content-Type 头部:application/jwt

可通过 [**api.ibkr.com/oauth2/api/v1/jwks**](https://api.ibkr.com/oauth2/api/v1/jwks) URL 查找用于验证签名的相应公钥。
