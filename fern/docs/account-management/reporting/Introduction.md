# 简介

IBKR 提供全面的报表功能,以满足你的业务需求。本节将详细介绍如何通过我们的 API 访问各类报表。

* **[活动对账单](/account-management/reporting/activity-statements)**:活动对账单反映所有账户活动,包括现金交易、股息、公司行动和交易。
* **[税务表格](/account-management/reporting/tax-forms)**:访问最近 5 年的税务文件。
* **[交易确认](/account-management/reporting/trade-confirmations)**:为所有成交实时生成的交易确认。
