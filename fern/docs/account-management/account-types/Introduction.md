# 简介

在本节中,我们将详细介绍所支持的各种账户类型。每种账户类型都旨在满足特定的用户需求,并具有各自的一套功能、能力和限制。了解这些账户类型之间的差异,将有助于您根据自身需求选择最合适的选项,并确保您能够使用所需的功能。

请注意,与我们的前端所支持的账户类型相比,通过 API 支持的账户类型较为有限。通过 API 支持的账户类型取决于用户需求。如果您有兴趣使用某种目前尚不支持的账户类型,请联系您的客户代表讨论您的需求。
