# 简介

`/api/v1/accounts/{{accountId}}/details` 端点可用于基于 `accountId` 查看账户信息。

该端点返回的数据与 IBKR 日终 Acct\_Status 中返回的数据相同,包括:

* 申请信息(开始日期、批准日期、开户日期、状态、注资日期、申请人类型、外部 ID)
* 个人资料信息(姓名、地址、联系信息、就业信息、身份证明文件信息、已接受的签名)
* 费用配置及生效日期
* 账户配置(基础货币、权限、特殊计划(包括 SYEP 和 DRIP)、MIFID 类别、市场数据订阅)
* 交易能力(已请求、已批准、已激活、保证金类型、期权级别)
* 财务信息(净资产、收入、财富来源)
* 适当性(投资目标、知识与经验)
* 风险评分
* 用户(用户名、上次登录、双因素认证、上次登录)
