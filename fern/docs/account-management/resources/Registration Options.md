# 注册选项（Registration Options）

IBKR 系统（包括注册系统 Registration、客户门户 Client Portal 和电子邮件 Emails）可以定制（免费），以体现您的公司品牌，包括徽标、公司名称和主题文件。

* [自定义主题文件](https://ibkrguides.com/brokerportal/whitebranding/custom-theme.htm)
* [注册与门户](https://ibkrguides.com/brokerportal/whitebranding/whitereg.htm)
* [电子邮件](https://ibkrguides.com/brokerportal/whitebranding/whiteemail.htm)

### 将 IBKR 托管的应用程序嵌入网站

将[全电子（Fully Electronic）](https://guides.interactivebrokers.com/bp/Default.htm#inviteclientstartelectronicapp.htm?TocPath=Dashboard%257CClient%2520Applications%257C_____2)申请嵌入您的网站，当客户点击申请链接时，将被重定向到经过白标处理的 IBKR 托管应用程序。客户将通过 IBKR 应用程序完整填写申请并提交给\
IBKR 处理。

* 展示自己的协议/预资格审查问题（如需要）
* 免费提供给注册顾问（Registered Advisor）和介绍经纪商（Introducing Broker）
* 涉及极少的开发工作
* 注册流程 100% 电子化
* 申请由 IBKR 托管

## 工作流程

为[电子邮件](https://www.ibkrguides.com/brokerportal/whitebranding/whiteemail.htm)以及[客户门户、注册系统、对账单和 PortfolioAnalyst](https://guides.interactivebrokers.com/bp/Content/whitebrandingportal.htm)配置白标

1. IBKR 门户可以定制（免费），以体现您的公司品牌，包括徽标、公司名称和[主题文件](https://ibkrguides.com/brokerportal/whitebranding/custom-theme.htm)。生成指向该应用程序的 URL
2. 在 IBKR 门户中，选择 Settings > Client [账户模板（Account Template）](https://guides.interactivebrokers.com/bp/Default.htm#clientaccounttemplatesnew.htm)。
3. 选择 'Chain'（链条）图标
4. 复制超链接
5. 将超链接嵌入网站
6. 您可以提出预资格审查问题/展示自己的表单，然后根据答案将客户引导至特定的客户账户模板。![](https://www.ibkrguides.com/dameca/Resources/Images/image22.png)

### 向您的客户发送全电子申请

向您的潜在客户发起电子邮件邀请，随后该客户需使用[全电子（Fully-Electronic）](https://www.ibkrguides.com/brokerportal/homemenu/inviteclient.htm?Highlight=Fully-Electronic)申请在线以电子方式完成申请。

* 免费提供给注册顾问和介绍经纪商
* 无需开发工作
* 注册流程 100% 电子化
* 申请由 IBKR 托管

## 工作流程

可帮助简化全电子申请的工具：

* **账户模板（Account Templates）**：客户账户模板用于简化申请。使用[账户模板](https://www.ibkrguides.com/advisorportal/clientaccttemplates.htm?Highlight=template)指定账户类型、基础货币、交易功能、交易权限、财务信息和费用配置。
* **CRM**：使用 CRM 工具预填充全电子申请。客户将收到一封包含预填申请的电子邮件。CRM 工具和客户账户模板的使用可以填充申请的 90%。完成后，客户可以以电子方式将申请提交回 Interactive Brokers。
  * 手动或使用导入功能批量将联系人添加到 IBKR 的 [CRM](https://www.ibkrguides.com/advisorportal/homemenu/addcontact.htm)。
  * 从 CRM 联系人发起邀请
  * 选择 'Contacts' > 选择单个联系人 > 选择 ![](https://www.ibkrguides.com/dameca/Resources/Images/image1.png) 图标以发送申请邀请 > 指定申请方式（全电子）
  * 是否使用模板？
  * 如果是，则选择模板
  * 潜在客户将收到开始 IBKR 申请的电子邮件邀请。
  * 当潜在客户点击超链接开始申请时，申请将预先填入在 CRM/模板中输入的数据。客户可以根据需要修改信息。
  * 用户将被要求输入以下信息：
    * 创建用户名和密码
    * 设置 3 个安全问题及答案
    * 填写监管信息
    * 指定入金方式
    * 指定第二持有人信息（仅限联合账户）
* 完成后，客户可以以电子方式将申请提交回 Interactive Brokers。

### 为您的客户完成半电子申请

使用[半电子（Semi-Electronic）](https://www.ibkrguides.com/brokerportal/homemenu/startsemielectronic.htm?Highlight=Semi-Electronic)方式，您将为潜在客户在线完成一份电子申请。在流程结束时，您将生成一份 PDF 申请。将该 PDF 申请提供给潜在客户审阅并签署（需要实体签名）。

* 免费提供给注册顾问和介绍经纪商
* 无需开发工作
* 申请需要已签署的政府签发身份证件 + 实体签名
* 申请由 IBKR 托管

IBKR 的 [CRM](https://www.ibkrguides.com/advisorportal/homemenu/addcontact.htm) 可用于预填充半电子申请。

### 批量上传（Mass Upload）

批量上传专为寻求以无缝方式高效迁移 20+ 名客户至 IBKR 的顾问/经纪商而设计。无需为每个账户单独完成申请，可以通过在 Excel 工作簿中提供申请数据来批量开户。

* 免费提供给注册顾问和介绍经纪商
* 注册流程 100% 电子化
* 申请由 IBKR 托管
* 针对现有客户群的批量上传

## 工作流程

1. IBKR 将按账户类型向 FA/经纪商提供电子表格。
2. FA/经纪商将用客户信息填写电子表格并提交给 IBKR 处理。
3. IBKR 将上传这些账户并向 FA/经纪商提供账户凭据。
4. 顾问/经纪商将向其客户提供这些凭据。
5. 客户需要登录 IBKR 白标门户查看申请信息，并以电子方式签署 IBKR 协议/披露文件。

### 将现有账户关联至顾问/经纪商

现有 IB 账户可以直接通过客户门户关联到顾问/经纪商名下。

* 免费提供给注册顾问和介绍经纪商
* 注册流程 100% 电子化

## 工作流程

1. **发起关联请求**
   * 选项 1：在您的网站上嵌入 URL，用户可通过该 URL 提交关联到您主账户的请求。
     * `https://ndcdyn.interactivebrokers.com/sso/Login?forwardTo=AA\_LINKAGE&masterAccountId=<InsertMasterAccountIDHere>`
   * 选项 2：共同客户可以在 Client Portal > Settings > Account Settings > [创建、移动、关联或拆分账户。](https://www.ibkrguides.com/clientportal/createlinkedaccountunderadvisorbroker.htm?Highlight=link%20account)中发起关联到顾问/经纪商的请求。
2. 确认关联请求
   * 系统将向顾问/经纪商发送电子邮件告知该请求。在账户完成关联之前，顾问/经纪商必须（在待处理事项 Pending Items 中）接受该关联请求。

### 完全集成 - 通过 Web API 进行客户注册

适用于希望自定义注册系统、门户以及资金与银行系统的顾问/经纪商。账户管理 Web API 可用作 IB 托管门户的替代方案。

* 面向具备 OAuth 2.0 和 JSON 实用知识的顾问/经纪商。
* 控制应用程序的外观、体验和流程
* 注册流程 100% 电子化
* 申请由合作方（Counterparty）托管
* 需要管理层批准——申请将逐案审核。
* 通常，计划在首个季度内引入 100+ 个账户或 5000 万美元（50M USD）的顾问/经纪商符合使用此服务的条件。
* 托管申请的顾问和经纪商需支付一次性费用和持续费用，用于抵消 IBKR 为审查初始请求所产生的成本，并对托管应用程序进行年度审查。此年度审查旨在确保托管应用程序已更新以反映 IBKR 对其自身应用程序所做的更改，并且顾问或经纪商未引入任何其他会导致 IBKR 拒绝该托管安排的更改。

## 工作流程

1. 顾问/介绍经纪商（IBroker）在其网站上构建界面，以收集所有必填的 IBKR 申请字段，并收集 IBKR 协议/披露文件的签名
2. 顾问/IBroker 使用 Web API 以 JSON 格式将所有数据以及已签署的协议和披露文件发送给 IBKR。
3. IBKR 检索文件并提供响应文件。响应状态为 Success 或 Error。任何错误将由顾问/IBroker 修正后重新提交。
4. 成功的响应文件将包含 IB 账户号、用户名、临时密码、已成功处理的协议/披露文件的确认，以及审批所需的待处理注册任务（如有）。
   * 如果响应文件中不包含注册任务，该账户将被提交审批。
   * 如果包含注册任务，则需要完成[注册任务](/web-api/account-management/client-registration/registration-tasks/complete-registration-tasks)，账户才能继续审批流程。
5. 顾问/IBroker 负责向其客户提供账户号、用户名和临时密码。
6. 在账户获得批准并开立后，客户首次登录 IBKR 门户时，将被提示重置密码并设置三个安全问题。

### 混合模式（Hybrid）

通过 Web API 向 IBKR 提供部分账户数据。客户将通过 IBKR 托管的应用程序（白标）完成剩余的申请步骤。

* 顾问/经纪商可以将客户引导至 IBKR 的登录页面（白标），或创建[单](/web-api/account-management/single-sign-on)[点登录](https://www.ibkrguides.com/dameca/Endpoint/ssoCreate.htm)（single sign on）会话以完成剩余的申请步骤。

* 面向具备 JSON 和 OAuth 2.0 实用知识的顾问/经纪商。

* 注册流程 100% 电子化

* 申请由 IBKR 托管

* 涉及中等程度的开发工作

## 工作流程

顾问与 Fully-Disclosed 客户的工作流程

1. **在 IBKR 创建账户**
   * 使用 [accounts](https://ibkrcampus.com/docs/web-api/api-reference/account-management/account-management-accounts/create-accounts) 端点向 IBKR 提交部分申请数据。
     * 开立账户至少需要提供姓名（Name）、电子邮件（Email）和居住国家/地区（Country of Residence）。
     * [必填字段](/web-api/account-management/client-registration/data-for-client-registration)
   * IBKR 将返回实时的[响应](/web-api/account-management/resources/sample-responses/sample-responses)，其中包含账户凭据和待处理任务。
2. **引导用户前往 IBKR 门户完成剩余的申请步骤。**
   * 创建[单](https://www.interactivebrokers.com/campus/ibkr-api-page/webapi-ref-staging/#tag/Authorization-SSO-Sessions/paths/~1gw~1api~1v1~1sso-sessions/post)[点登录](https://www.ibkrguides.com/dameca/Endpoint/ssoCreate.htm)会话，将用户无缝连接到 IBKR 门户。
   * IBKR 门户可以定制（免费），以体现您的公司品牌，包括[徽标、公司名称](https://ibkrguides.com/brokerportal/whitebranding/whitereg.htm)和[主题文件](https://ibkrguides.com/brokerportal/whitebranding/custom-theme.htm)。这可以直接在 IBKR 门户中进行配置。
3. **设置密码并完成电子邮件验证（可选）**
   * 如果在 IBKR 托管门户内设置/更改银行指令或办理出金，则需要使用用户名和密码进行 IBKR 身份验证。
   * API 支持为美国客户创建 ACH 指令。对于所有其他客户，出金用的银行指令需要在 IBKR 门户内添加；这意味着账户上需要设置密码。
   * IBKR 提供两种设置密码的方式（如果选择方式 2，即批准后设置，请跳至步骤 4）。
   * **方式 1：在注册过程中设置密码（建议）**
     * 访问 IBKR 门户后，用户将被提示输入临时密码（包含在响应文件中）并设置新密码。\
       ![](https://www.ibkrguides.com/dameca/Resources/Images/image13.png)\
       IBKR 将发送电子邮件确认令牌以验证身份。电子邮件将带有您公司的徽标和回信邮箱地址。\
       ![](https://www.ibkrguides.com/dameca/Resources/Images/image15.png)\
       电子邮件示例\
       ![](https://www.ibkrguides.com/dameca/Resources/Images/image16.png)\
       密码更改已处理完成。\
       ![](https://www.ibkrguides.com/dameca/Resources/Images/image18.png)
   * **方式 2：批准后设置密码**
     * 合作方将引导用户前往 IBKR 的密码重置工具设置密码。
     * 用户输入 IBKR 用户名和出生日期。
     * IBKR 将发送短信（SMS）令牌以验证身份。
     * 用户将设置密码并完成电子邮件验证。
4. 用户完成剩余的申请步骤。
   * 申请将预先填入用于创建账户的 XML 文件中包含的信息。
