# 客户注册所需数据

通过我们的 API 建立客户账户所需的信息取决于以下几个关键因素:

1. **客户类型(Customer Type)**
   * FD= 全披露介绍经纪商(Fully-Disclosed Introducing Broker)
   * FA= 注册投资顾问(Registered Investment Advisor)
   * OWD= 单向披露介绍经纪商(One Way Disclosed Introducing Broker)
   * NonQI= 非披露介绍经纪商;非合格中介(Non Qualified Intermediary)
   * QI with Trading= 非披露介绍经纪商;合格中介(Qualified Intermediary),客户可以进行交易
   * QI with No Trading= 非披露介绍经纪商;合格中介,客户无法通过 IBKR 系统进行交易(例如,交易将通过 FIX 下达)。
2. **注册类型(Registration Type)**
   * 混合模式(Hybrid)
   * 完全集成(Full Integration)
3. **账户类型(Account Type)**
   * 零售(Retail)= 个人(Individual)、联合(Joint)、退休(Retirement)、ISA
   * 机构(Entity)= SMSF、信托(Trust)、组织(Organization)
4. **IBKR 实体(IBKR Entity)** *由主账户所关联的实体决定。虽然接受来自[所有国家](https://www.interactivebrokers.com/en/index.php?f=7021\&nhf=T)的公民或居民的开户申请(被美国外国资产控制办公室禁止的国家/地区的公民或居民除外),但顾问/经纪商为居住在以下国家/地区的申请人开户可能会受到限制:*
   * **美国:** 仅适用于总部位于美国的 IB-LLC 经纪商和顾问。
   * **加拿大**:仅适用于 IB-CAN 经纪商和顾问。
   * **香港:** 仅适用于 IB-HK 经纪商和顾问。
   * **澳大利亚**:仅适用于 IB-AU 经纪商和顾问。
   * **日本**:仅适用于已完成 FSA 注册的 IBLLC 经纪商和顾问。
   * **英国**:仅适用于 IB-UK 经纪商。
   * **新加坡**:仅适用于 IB-SG 经纪商和顾问。
   * **EEA(欧洲经济区)**:仅适用于 IB-IE 或 IB-CE 经纪商和顾问。
