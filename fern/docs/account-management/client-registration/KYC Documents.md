# KYC 文件

### 身份与地址验证

对于所选国家/地区,系统会在创建账户时进行 Trulioo 实时验证。如果 Trulioo 验证未成功,或者 Trulioo 验证不受支持或申请人居住的国家/地区不在支持范围内,则需要通过身份与地址验证才能获得批准。

#### 其他国家/地区

### 身份与地址验证选项

#### 选项 1:传统验证

向客户收集身份证明和地址证明文件,并将文件提交给 IBKR 的 `documentSubmission`。

**注册任务**

* 8001:身份证明(POI)
* 8002:地址证明(POA)

需要注意:对于 IB-HK 非披露(Non-Disclosed)(QI 和 NonQI)客户,我们仅要求提供身份证明(8001)。

**处理时间**

IBKR 采用" follow the sun(日不落)"模式,操作人员遍布全球,持续审核并处理新申请的支持文件。文件通常在 24 小时内处理完毕。也就是说,账户会在 IBKR 接受支持文件后的 24 小时内获得批准/开通。\
导致延误的原因可能是提交的文件类型不受支持,或收到的图像模糊/过暗。

#### 选项 2:即时验证

可选择允许客户使用 Au10tix(用于验证客户身份/地理位置的第三方应用程序)进行验证。

* 如果 Trulioo 返回 NoMatch,IBKR 将传递一个唯一的 URL,该 URL 可用于将用户连接到 Au10Tix 以完成验证。该 URL 的有效期为 24 小时。如果超过 24 小时,则需要使用 `/api/v1/accounts/{{accountId}}/kyc` 端点生成新的 URL。

**工作流程**:

* 在应用程序中嵌入 Au10Tix URL,或提供包含 Au10Tix URL 的二维码。
* 用户访问 Au10Tix URL 后,系统会提示其完成同意声明,确认允许 Au10Tix 采集生物识别信息。
  * 如果用户同意,系统将提示其拍摄证件正面和背面的照片并进行自拍。
  * Au10Tix 将处理相关信息并完成身份验证。
  * 如果 Au10Tix 验证失败,用户将需要完成"传统验证",并提供地址证明和身份证明文件。
* 如果用户拒绝同意,系统将提示其完成传统验证。

**处理时间**

实时验证即时完成——如果 Au10Tix 验证通过,账户将获得实时批准/开通。

**注册任务**

* 8137:Au10Tix 身份与地址验证
* 8437:Au10Tix 身份验证

**重要提示:** 虽然合作伙伴可以将传统验证作为其主要验证方式,但在由 IBKR 合规部门判定的某些基于风险的场景中,即使最初分配或已完成传统验证,也可能要求进行 Au10tix 验证。此要求不可协商,由 IBKR 的内部风险评估协议触发。若未能同时支持这两种验证方式,可能导致用户在某些场景下无法完成开户流程。所有合作伙伴都应通过直接 API 实现或 SSO 回退能力来支持这两种验证路径。
