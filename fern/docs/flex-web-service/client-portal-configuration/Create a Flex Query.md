# 创建 Flex Query

回到 Flex Queries 页面,现在我们需要生成至少一个 Activity Flex Query(活动 Flex 查询)或 Trade Confirmation Flex Query(交易确认 Flex 查询)。

*[图] 突出显示 Flex Queries 页面中的 Activity Flex Query 和 Trade Confirmation Flex Query 部分。*

接下来,点击某个 Flex Query 左侧的 **Info** 图标。

*[图] 突出显示某个 Flex Query 的 Information 按钮。*

在弹出的信息浮窗中,记下列在顶部的 **Query ID** 编号。生成报告时将会用到它。

*[图] 突出显示某个特定 Flex Query 的 Query ID。*
