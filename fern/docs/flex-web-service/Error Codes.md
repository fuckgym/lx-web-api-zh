# 错误代码

以下是 [/SendRequest 端点](/docs/web-api/api-reference/send-request)和 [/GetStatement 端点](/docs/web-api/flex-web-service/retrieve-the-report)在发生服务器端故障时可返回的错误代码汇总列表。

| ErrorCode | ErrorMessage                                                                                                                                        |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1001      | 当前无法生成对账单。请稍后重试。                                                                                       |
| 1003      | 对账单不可用。                                                                                                       |
| 1004      | 对账单目前尚不完整。请稍后重试。                                                                                         |
| 1005      | 结算数据当前尚未就绪。请稍后重试。                                                                                         |
| 1006      | FIFO 盈亏数据当前尚未就绪。请稍后重试。                                                                                     |
| 1007      | MTM 盈亏数据当前尚未就绪。请稍后重试。                                                                                      |
| 1008      | MTM 与 FIFO 盈亏数据当前尚未就绪。请稍后重试。                                                                                   |
| 1009      | 服务器负载过高。当前无法生成对账单。请稍后重试。                                                                                     |
| 1010      | 不再支持旧版 Flex 查询。请转换为 Activity Flex。                                                                                |
| 1011      | 服务账户处于非活动状态。                                                                                                  |
| 1012      | 令牌已过期。                                                                                                        |
| 1013      | IP 限制。                                                                                                         |
| 1014      | 查询无效。                                                                                                         |
| 1015      | 令牌无效。                                                                                                         |
| 1016      | 账户无效。                                                                                                         |
| 1017      | 参考代码无效。                                                                                                       |
| 1018      | 该令牌发出的请求过多。请稍后重试。限制为每秒 1 个请求、每分钟 10 个请求(每个令牌)。                                                     |
| 1019      | 对账单正在生成中。请稍后重试。                                                                                             |
| 1020      | 请求无效或无法验证请求。                                                                                                  |
| 1021      | 当前无法获取对账单。请稍后重试。                                                                                           |
